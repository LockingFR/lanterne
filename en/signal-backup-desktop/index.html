Signal Desktop backup: create it and read it

Back up Signal Desktop on Windows, Mac or Linux and read the messages with your recovery key.

Create the backup

  1. In Signal Desktop, open Settings › Backups, then Other ways to back up.
  2. Choose a folder. Don't rename it afterwards.
  3. Save the 64-character recovery key.

Read it

The folder is already on your computer: choose it in Lanterne, paste the key and decrypt.

Restore it

Restoring happens in the Signal app. According to Signal support, restoring a Desktop backup on iPhone is not supported: check their page for the current status.

Never give your recovery key to anyone who asks for it by message or phone, even if they claim to work for Signal. Together with the backup, it unlocks all your messages.

Menu labels can vary between versions. Reference: Signal support.
