Restauration Signal échouée : que vérifier

La restauration Signal échoue ? Dossier incomplet, mauvaise clé, étape passée : les vérifications, et comment relire vos messages quand même.

Les vérifications

  • Le bon dossier. Sélectionnez le dossier de sauvegarde entier, pas un fichier à l'intérieur.
  • Le bon appareil. Le dossier doit être présent sur le téléphone où vous restaurez. S'il n'apparaît pas, redémarrez-le.
  • Le bon moment. La restauration se propose pendant l'inscription. Si vous avez passé l'étape, il faut en général recommencer l'inscription. Attention : réinstaller efface les messages présents ; ne le faites pas si le téléphone contient des messages non sauvegardés.
  • La bonne clé. Une nouvelle clé n'ouvre pas les anciennes sauvegardes. Signal ne peut pas récupérer une clé perdue.

Relire vos messages quand même

Gardez une copie intacte du dossier, puis ouvrez-la dans Lanterne. Si elle s'ouvre, la clé est bonne et le fichier des messages est intact. Vous pourrez lire et exporter vos conversations, mais pas les remettre dans Signal.

Ne donnez jamais votre clé de récupération à quelqu'un qui vous la demande par message ou par téléphone, même s'il dit travailler pour Signal. Avec la sauvegarde, elle donne accès à tous vos messages.

Les libellés des menus peuvent varier selon la version. Référence : l'assistance de Signal.
