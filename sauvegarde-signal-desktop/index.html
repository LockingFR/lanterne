Sauvegarde Signal Desktop : la créer et la lire

Sauvegarder Signal Desktop sur Windows, Mac ou Linux et relire les messages avec la clé de récupération.

Créer la sauvegarde

  1. Dans Signal Desktop, ouvrez Réglages › Sauvegardes, puis les autres moyens de sauvegarder.
  2. Choisissez un dossier. Ne le renommez pas ensuite.
  3. Enregistrez la clé de récupération de 64 caractères.

La lire

Le dossier est déjà sur l'ordinateur : choisissez-le dans Lanterne, collez la clé, puis déchiffrez.

La restaurer

La restauration se fait dans l'application Signal. D'après l'assistance de Signal, restaurer une sauvegarde Desktop sur iPhone n'est pas pris en charge : vérifiez sa page pour l'état actuel.

Ne donnez jamais votre clé de récupération à quelqu'un qui vous la demande par message ou par téléphone, même s'il dit travailler pour Signal. Avec la sauvegarde, elle donne accès à tous vos messages.

Les libellés des menus peuvent varier selon la version. Référence : l'assistance de Signal.
